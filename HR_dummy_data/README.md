# HR Dummy Data

This folder contains fictional test data for the local HR screening application described in `HR_build.md`.

## Structure

- `candidates/batch_01/` contains ten growth and demand marketing CV PDFs.
- `candidates/batch_02/` contains ten brand and integrated marketing CV PDFs.
- `listing/listing_01/listing_01.txt` and its scoring template describe a Growth Marketing Manager role.
- `listing/listing_02/listing_02.txt` and its scoring template describe a Brand Marketing Manager role.

All names, contact details, companies, employment histories, and performance figures are fictional and intended only for local testing. The CVs are real PDF files with extractable text, not placeholder filenames.
